# موقع أكوا جولد (كتالوج عرض منتجات)

موقع ثابت من ملف واحد: `index.html` والصور في `img/`. مافيهوش قاعدة بيانات ولا سلة.

## تعدّل إيه منين
افتح `index.html` في أي محرر، وروح لآخر الملف على الجزء اللي عليه `البيانات: عدّل هنا`:
- `PHONE`: رقم الواتساب والاتصال.
- `OFFER_END`: آخر يوم في العرض. بعد التاريخ ده شريط العرض وقسمه بيختفوا لوحدهم.
- `PRODUCTS`: المنتجات. كل منتج فيه الاسم والصورة والوصف والنقط ورسالة الواتساب.
  لما تعرف أنواع الفحم النشط وأسماء المعدات، اكتبها في `points` بتاعة كل منتج.

## تجربته على الجهاز
```
uv run --no-project python -m http.server 5507
```
وبعدين افتح http://127.0.0.1:5507

## النشر
ارفع الفولدر كله (index.html + img) على GitHub Pages أو على أي استضافة.
